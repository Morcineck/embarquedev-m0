# Ambiente de desenvolvimento

- **Sistema operacional:** Microsoft Windows 11 Home
- **Versão do Git:** git version 2.54.0.windows.1
- **Editor/IDE:** IntelliJ IDEA
- **Linguagem principal:** Java

## Como verifico o estado do repositório

Uso `git status` para ver quais arquivos foram alterados e o que já está no
staging, `git diff` para ver as mudanças linha a linha antes de adicionar e
`git log --oneline --graph` para conferir o histórico e as branches antes e
depois de cada commit.
